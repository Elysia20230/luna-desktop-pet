# 樱小路露娜 · 桌面宠物

> 《近月少女的礼仪》里的**樱小路露娜**，住在你的电脑桌面上。
> 她会跟你聊天、记得你说过的事、偷偷看你在干什么，并按心情换表情。

**这是一个能跑的桌面宠物程序**：Python + PySide6，真透明置顶，接任意 OpenAI 兼容大模型，
可选本地日语语音合成与本地语音识别。代码 MIT，已打包成 Windows exe。

> ⚠️ **立绘与语音另附素材包**：角色素材是游戏版权物，**不在本仓库里**（`.gitignore` 已排除）。
> 到 [Releases](../../releases) 下载 `luna-assets-v*.zip`，把里面的
> `Sprite` 与 `assets` 文件夹解压到 `LunaPet.exe` 旁边（同一个文件夹）——
> 程序启动时会自己找到，不用配置。
> 也可以把 `Sprite` 放在任意位置，再在 设置 → 立绘 → 选目录 指过去；
> 语音想用自己的录音，就在 设置 → 其它 →「彩蛋音频」里选一个 wav。
> 命名规则是 `lun_<尺寸 f/s/m/l>_<服装>_<动作>_<表情编号>.png`（示例见 `docs/修改指南.md` §3）。
> 素材版权归原权利人（Navel），仅限个人研究使用，请勿商用或再分发；权利人要求即撤。

## 一、她能做什么

| 能力 | 说明 |
|---|---|
| **透明桌宠** | 无边框、真透明、始终置顶；拖哪放哪，位置会记住。 |
| **能聊天** | 双击她 → 输入框就出现在她脚下（跟着她走，不会跑出屏幕）。接入 DeepSeek（OpenAI 兼容接口），流式逐字回复，她的话显示在头顶气泡里。**没填 Key 也能用**——她会念内置台词。 |
| **聊天记录** | 她说过的话都留在 `data/history.json`，随时在「聊天记录」窗口里翻、也能一键清空。 |
| **会发语音**（可选） | 接本地 GPT-SoVITS：文字仍是中文，念出来是露娜的日语。**按情绪自动换音色**（平静/平淡/柔和/质问四套），长句会自动断句边合成边播。 |
| **像露娜** | 人设直接读工作区里的露娜系统提示词，性格真实丰富。 |
| **有记忆** | 每 8 轮自动提炼"关于你的事"，存成明文事实卡；下次靠语义检索（硅基流动 `bge-m3` + 本地 ChromaDB）想起来。 |
| **看屏幕** | 右键「看看我在干什么」= 现拍一张，她**就着画面随口点评一句**（头顶气泡 + 可选日语朗读）。这**不算一次对话**：不写聊天记录、不触发记忆提炼。窗口标题命中"密码/银行/支付"等词时直接不截图。 |
| **随情绪换表情** | 回复里自带情绪标记，12 档情绪 → 自动换成对应表情差分。 |
| **随情绪换动作** | 得意、生气、无语、思考时会从「抬手」换成「抱臂」，**衣服不换**；说完 N 秒自动回到默认姿势（可关）。 |
| **换装 / 换尺寸 / 缩放** | 13 套造型 × 4 个尺寸族（头部/半身/中景/近景）× 0.3~2.0 缩放。 |
| **按时段/季节主动更换服饰** | 深夜 22:00–06:00 自动换**睡衣**；12–2 月、9–11 月绝不会随机穿短袖和蕾丝礼服，夏季也不会披大衣。同一时段里随机挑，但只在她开口时才换，不会每句话都变。手动换过的衣服 2 小时内不会被自动覆盖。 |
| **她说一句，你可以接** | 她主动开口时，气泡下方出现「嗯？」「我在呢」这类按钮，点一下就算接话；也可以点「自己写…」打字。12 秒没点自动收起，不拦着你干活。 |
| **会眨眼、会呼吸** | 闲置时的两个小动作，能关掉。 |
| **会自己找你说话** | 隔一阵没人理，她主动冒一句（头顶小气泡，不抢焦点、不挡操作）；可选先偷看一眼屏幕再开口。 |
| **你可以是女仆朝日，也可以是任何人** | 设置 → 对话 →「我是谁」切换身份，她换一套态度和称呼（角色卡在 `assets/roles.json`，可自己加人）。 |
| **能语音通话**（可选） | 右键「语音通话」或设置里的开关：对着麦克风说话，她听（本地 `faster-whisper`，**免费、离线、不上传录音**）、答、念出来，说完再听。也可以边打电话边打字。 |
| **知道现在的时间** | 每次开口都带着当前的日期、星期、时段（早上/深夜…），以及"距上次说话多久"。问她"今天几号""刚才隔了几天"不会瞎猜。 |

## 二、三步开始用

**用打好的 exe（推荐给别人）**：去 [Releases](https://github.com/Elysia20230/luna-desktop-pet/releases) 下
`luna-desktop-pet-v*-win64.zip`，解压后双击 `LunaPet.exe`。

**从源码跑**：双击 `启动露娜.bat`，露娜就出现在屏幕右下角。

1. **双击立绘** 打开脚下的输入框，直接说话试试（此时是内置台词）。
2. 想让她真正"活过来"：**右键立绘 → 设置 → 对话**，选服务商、填 API Key，保存。

> 支持的服务商：DeepSeek / OpenAI / 硅基流动 / Moonshot(Kimi) / 智谱 GLM / 阿里百炼(DashScope) / 本地 Ollama / 任意自建反代。
> 每家 Key 分开记，切换回来不用重填；模型名可以直接手打。换一家只改这两行，
> 记忆、翻译、语音全都跟着走同一个接口。

> 启动失败不会"闪一下就没了"：会弹出一个中文提示窗，说明原因，并且把完整日志写到
> `logs\启动错误.txt`。想看更完整的控制台输出，就用 **`启动露娜_调试.bat`**。

> ⚠️ 两个 `.bat` 是 **GBK 编码 + CRLF 行尾**（cmd.exe 的硬要求）。
> 不要用记事本"另存为"改成 UTF-8，否则会再次出现"不是内部或外部命令"的乱跳报错。
> 改坏了可以运行 `tools\build_launchers.py` 原样重新生成。

### 首次配置（都在「设置」里，不用改代码）

| 要填的 | 在哪 | 不填会怎样 |
|---|---|---|
| 任意支持的服务商 Key | 设置 → 对话 | 只会说内置台词，不联网 |
| embedding记忆模型 Key（可选） | 设置 → 记忆 | 记忆检索退化成"本地哈希向量"，仍可用但不那么懂语义 |
| 视觉模型（可选） | 设置 → 看屏幕 | 只能根据"窗口标题"搭话，不截图、不上传画面 |

### 环境准备

需建立虚拟环境（Python 3.12 + PySide6 6.12 + chromadb 1.5.9），
`启动露娜.bat` 会直接用它。如当前无环境依赖，请按下面两步重建：

```bat
:: 1) 建虚拟环境（在 LunaPet 目录里执行）
python -m venv .venv

:: 2) 装依赖（国内建议加镜像，官方源经常卡住）
.venv\Scripts\python.exe -m pip install -i https://mirrors.aliyun.com/pypi/simple -r requirements.txt
```

装完可自检一遍（不联网、不弹窗）：

```bat
.venv\Scripts\python.exe launcher.py --check      :: 一条命令查环境是否齐
.venv\Scripts\python.exe -m pytest tests -q
.venv\Scripts\python.exe tools\smoke_offscreen.py
```

## 三、怎么操作

### 立绘上

| 操作 | 效果 |
|---|---|
| 左键拖动 | 搬家（她脚下的输入框会跟着一起走） |
| 滚轮 | 放大 / 缩小 |
| 双击 | 在脚下打开输入框（再双击 / 按 Esc 收起） |
| 右键 | 菜单：说话、看屏幕、语音通话、换造型（含「按时间自动换装」开关）、换动作、换尺寸、缩放、聊天记录、语音朗读、设置、记忆、退出 |

### 输入框（她脚边那条）

| 操作 | 效果 |
|---|---|
| 回车 | 发送 |
| Esc | 收起 |
| 「记录」按钮 | 打开聊天记录窗口 |
| 拖动她 | 输入框实时跟随；脚下放不下会自动翻到她头顶，再放不下就贴在屏幕边上 |

### 聊天记录窗口

只读窗口，能看到全部你来我往；「清空」会连同 `data/history.json` 和她这段的短期记忆一起清掉。
「看屏幕 / 设置 / ×」跟以前一样。

### 托盘图标（右下角）

单击打开输入框；右键可以显示/隐藏立绘、聊天记录、设置、记忆、退出。**立绘不小心被拖出屏幕时，用它叫回来。**

立绘素材不在仓库里，按下面的顺序自动查找（`app/config.py::sprite_dir`）：

1. 设置里指定的「立绘目录」
2. `LunaPet.exe` 同级的 `Sprite\`（**推荐**：把素材包解压到这里）
3. 上一级目录的 `Sprite\`（源码运行时就是项目旁边的 `../Sprite`）
4. 打包内部（正常用不到）

找不到时程序照常启动，托盘会提示去下载素材包。

彩蛋语音（`taihen_ni_kibun_ga_ii.wav`）按下面的顺序查找（`app/voice/signature.py`）：

1. 设置 → 其它 →「彩蛋音频」里指定的 wav
2. 打包内部 `assets\voice\`（源码运行时就是项目里的 `assets\voice\`）
3. `LunaPet.exe` 同级的 `assets\voice\`（**素材包解压后就在这里**）
4. `data\voice\`（随手扔一份也认）

## 五、常见问题

**Q：双击 bat 一闪就没？**
现在不会了：失败会弹中文提示窗，并把原因写进 `logs\启动错误.txt`。
想自己先查一遍，执行 `.venv\Scripts\python.exe launcher.py --check`。
如果提示缺少 PySide6，在 LunaPet 目录执行：
```
.venv\Scripts\python.exe -m pip install -i https://mirrors.aliyun.com/pypi/simple -r requirements.txt
```

**Q：控制台里一堆"不是内部或外部命令"？**
说明 `.bat` 被改成了 UTF-8 或 LF 行尾（cmd 只认 GBK + CRLF）。
运行 `tools\build_launchers.py` 重新生成即可，别用记事本改这两个文件。
**Q：装依赖时卡住不动？**
默认源（pypi.org）在国内经常卡在下载 PySide6 那一步，换成阿里云或清华镜像即可
（清华镜像对个别安装包会返回 403，阿里云目前正常）：
```
.venv\Scripts\python.exe -m pip install -i https://mirrors.aliyun.com/pypi/simple -r requirements.txt
```

**Q：露娜周围有黑底/白底？**
说明系统没开桌面合成（透明窗口需要）。Win10/11 默认是开的；远程桌面或某些精简系统会关掉。

**Q：填了 Key 还是说"钥匙不对"？**
Key 前后别有空格；（以deepseek为例）确认模型名是 `deepseek-chat`，接口地址是 `https://api.deepseek.com`。

**Q：填了 Key，发消息后一直停在"露娜正在斟酌用词…"？**
先看 `logs\运行错误.txt` 在不在——在的话，里面就是真正的原因（这是一个兜底日志，
以前这类错误会被 Qt 静默吞掉，所以你只看到"很慢"，其实一个字都没发出去）。
常见原因：Key 不对/欠费（状态行会显示错误提示）、`api.base_url` 被改成了带 `/v1` 的地址、
或者装完新版依赖后没有重启程序。关掉程序（托盘 → 退出）再启动一次通常就好。

**Q：记忆变多了会不会越聊越慢？**
不会。检索记忆和拼人设已经搬到后台线程做，且"给一句话算向量"最多等 8 秒
（`memory.embedding.query_timeout`），超时就退回关键词检索，界面不会卡。

**Q：她怎么突然自己说话了？**
那是"主动搭话"：超过「设置 → 其它 → 每隔多久主动说一句」的时间没人理她，她就在头顶
冒一个小气泡（默认 9 秒后自己消失，点气泡可以接着聊）。不想被打扰就把那个数字设成 0。
刚跟你说过话的几分钟内她是安静的（「你说话后多久内不打扰」）。

**Q：改了「每隔多久主动说一句」，可是她一直不说话？**
设置 → 其它 → 点「让她现在说一句」立刻试一次。
以前这里有个 bug：保存设置会重建对话引擎，但引擎的"主动搭话"信号没重新接上，
于是她其实生成了台词、界面却收不到（不报错、不写日志）。现在保存设置会自动重接，
并且如果"先瞄一眼屏幕"那一步截图失败，也会退回直接说话，不会把这次搭话吞掉。

**Q：设置里那个「心情大好～」是干什么的？**
设置 → 其它 → 点「让她说一句「心情大好～」」：桌面会放一段露娜的日语录音
（大変に気分がいい～），同时她换成抱臂得意的样子、头顶冒出中文「心情大好～」，8 秒后自己恢复。

它和上面几个"测试"按钮是分开的：不经过翻译、不经过语音服务、不写聊天记录，
所以语音开关关着、GPT-SoVITS 没启动，这个按钮照样能用。想换成自己的录音，
见 `docs/修改指南.md` §9.3。

**Q：从 Release 下的 exe，点「心情大好～」没声音？**
那段录音和立绘一样是游戏版权物，**没有打进程序包**，在素材包 `luna-assets-v*.zip` 里。
把它解压到 `LunaPet.exe` 旁边（会得到 `LunaPet\assets\voice\taihen_ni_kibun_ga_ii.wav`），
再点就有声了；也可以 设置 → 其它 →「彩蛋音频」直接指一个 wav。
点按钮时如果还找不到，托盘会把这几个"该在哪"的路径都列出来。

**Q：设置里「GPT-SoVITS 根目录」到底该选哪一层？**
选**解压出来、里面能直接看到 `api_v2.py` 和 `runtime` 文件夹的那一层**
（例如 `D:\GPT-SoVITS-v2pro-20250604`）。选深一层（选到 `runtime\` 或
`GPT_weights_v2Pro\`）时，设置页会立刻标红提示"这一层没有 api_v2.py"。
不想手动找就点旁边的「自动查找」，它会在 下载 / 桌面 / 用户目录 里浅扫一遍。
这一项只影响"用日语念出来"，不填也能正常聊天。

**Q：她为什么突然抱着胳膊？**
那是动作差分：得意、生气、无语、思考时会从「抬手」换成「抱臂」，衣服不变。
说完话 N 秒后（默认 8 秒）自动回到默认姿势；想立刻恢复就在立绘上右键 →「换动作」→
「恢复默认姿势」，或者关掉对话窗。不想让她自动换动作：设置 → 立绘 → 取消勾选。

**Q：下拉框里的字看不清？**
每个下拉框本身的底色和弹出列表的底色都调成了深底浅字，选中项是紫底白字。
如果你的系统主题特别特殊（比如高对比度模式），可以在 `app/ui/panels.py` 的 `_DIALOG_QSS`
里改 `QComboBox QAbstractItemView` 那几行。

**Q：「我是谁」里设置的用途是什么？**
露娜对不同的人脾气不一样。设置 → 对话 →「我是谁」选一下，她连称呼一起换（叫人方式写在
`assets/roles.json` 里，想加自己的角色卡就照抄一份、改 `id/label/rules`）。

**Q：勾了"先偷看一眼屏幕"会截图上传吗？**
不会，除非你在「设置 → 看屏幕」里另外配了视觉模型。只勾这个选项时，她只读当前窗口标题
和程序名——这也正是她说出"在打造我的桌宠呢"的原因。想看截图功能到底通不通，点
「测试一下截图」，会用托盘消息告诉你成功还是被系统挡住。

**Q：为什么点完「看看我在干什么」，聊天记录里没有这一句？**
故意的。偷看一眼不算一次对话：她只说一句点评（气泡 + 可选朗读），
既不写进 `data/history.json`，也不进「聊天记录」，更不会被当成"事实"提炼进记忆——
否则聊着聊着，记录里会凭空多出一堆「看看我在干什么？」。想接着聊就双击她打开输入框。
她正说着话时点这个会提示「她正说着呢」，不会打断当前这句。

**Q：隐私内容还会被截图吗？**
不会。窗口标题命中"密码/银行/支付/验证码/1Password"这类词时，程序在**截图之前**就返回，
只保留"瞄到一眼窗口标题"这个事实，她因此只会泛泛应一句。这条逻辑由
`tests/test_screen_privacy.py` 守着（命中隐私词时截图函数根本不会被调用）。

**Q：记忆里怎么什么都没有？**
记忆是聊出来的，而且需要填服务商 Key（提炼记忆要用模型）。也可以手动在「记忆」面板里加。

**Q：语音要等好几秒才有声？**
第一次一定会慢：GPT-SoVITS 服务本身要启动并加载模型，实测冷启动约 **25 秒**（其中 15 秒是服务启动），
之后每句**热服务首声约 5 秒**（翻译 ~1.4 s + 合成一段 ~4 s）。
现在她不会等整句话合成完才开口：回复一到就开始分段——**第一段说完就先出声，后面的边合成边接着播**，
句间几乎不空档。状态行会写「语音：正在启动服务…」，冷启动最多等 45 秒，等不到就给一句中文提示，不会一直装死。

**Q：怎么关掉语音 / 只让她偶尔出声？**
设置 → 语音 → 取消「用日语念出来」。也可以只关「主动搭话也念」——那样搭话还是出声，但回复不念（反过来也行）。
语音合成结果缓存在 `data/voice/`，同一句话第二次几乎是秒出；嫌占地方直接删那个目录。

**Q：想换她的声音 / 某一句音色不对？**
设置 → 语音 → 12 行「情绪 → 音色」自己调，保存后会写回 `assets/voice_emotions.json`（改前会自动留 `.bak`）。
音色来自 4 套参考音频（常态 / 平淡 / 柔和 / 质问），文件名和台词写在同一份 json 的 `refs` 里；
想加第五套，把 wav 放进模型目录、在 `refs` 里加一条即可，下拉框会自动出现。

**Q：她说的日语是什么意思？**
语音里念的是日语，屏幕上显示的中文才是"原话"——翻译只在朗读时用，聊天记录里保留中文。

**Q：语音通话怎么开？要联网吗？**
右键她 →「语音通话（对着麦克风说话）」，或 设置 → 语音 → 勾「实时语音通话」。
识别跑在**本机 CPU**（`faster-whisper`），录音不上传，也不花钱；只有把「识别后端」切成 `cloud` 才走硅基流动。
第一次开要下模型（约 145 MB，走 `hf-mirror.com`），提示「正在准备识别模型」就是它，下完存在 `data/models/`。

**Q：打电话时她不吭声 / 一直停在"识别中"？**
先看设置 → 语音里有没有一条**红字**：如果写着「Windows 正在禁止桌面应用使用麦克风」，就是系统隐私开关关着——
打开 `设置 → 隐私和安全性 → 麦克风 → 允许桌面应用访问你的麦克风`（设置页里也有「打开 Windows 麦克风设置」按钮直接跳过去），
改完把通话关掉再开一次即可。**Windows 自带的麦克风测试能用、她却听不见，通常就是这一条。**
没有红字的话：点「测试麦克风」录 3 秒，看音量条动不动；不动就换一支麦克风（下拉里带「（打不开）」的可以直接跳过），
或者调「多大声音算在说话」（环境吵调高到 0.02，说话轻调低到 0.004）。她念的时候是**停录**的（轮流说，不打自己的脸）。

**Q：她怎么知道现在是几号、多久没聊了？**
每次开口前都会自动带上当前的日期、星期、时段和"上一次说话隔了多久"，
提示词里要求「涉及时间一律以此为准，不要凭印象猜」。嫌占字数可以在配置里关掉 `behavior.time_aware`。

**Q：她怎么自己把衣服换了？我想一直穿某套。**
默认开着「按时间自动换装」：深夜穿睡衣、冬天不穿短袖，见上面的能力表。三种办法固定一套衣服：
① 右键「换造型」挑一套——手动选过的衣服 **2 小时内**不会被自动覆盖；
② 右键「换造型」→ 取消「按时间自动换装」（或 设置 → 立绘 → 取消同名勾选）；
③ 想改规则本身（几点算深夜、穿哪套当睡衣、最短多久换一次），见 `assets/wardrobe.json`
与 `docs/修改指南.md` §3.2。

**Q：她说了一句，我想接话怎么办？**
她已经主动开口时（气泡 + 可选朗读），气泡下方会有一排小按钮：「嗯？」「我在呢」「怎么了？」
按你原来的设定，点一下就等于把那句话发给她；点「自己写…」会打开输入框自己打。
12 秒没动就自动收起，点气泡本身也能直接打开输入框。按钮上的字在 设置 → 其它 →「她主动开口时给几个短回复」
里改（用 `/` 隔开），嫌烦就整组关掉。

**Q：会不会偷偷截图上传？**
默认**关闭**自动看屏幕。你点「看屏幕」才会截一张，而且只在设置了视觉模型时才发送；窗口标题命中"密码/银行/支付"等词时会主动跳过。截图不会落盘，除非你开了"保存调试文件"。

## 七、隐私

**Key 和聊天记录只存在你自己电脑上，没有遥测、没有默认上传。**

- API Key 存在 `config/config.json`（已加入 `.gitignore`，不会进仓库）。
- 聊天记录与记忆在 `data/`，日志在 `logs/`，都可以直接删。
- 截图只在你说"看"时发生，**不落盘**；命中隐私词（密码/银行/支付/验证码…）时连截都不截。
- 实时通话的录音**不出本机**（本地 faster-whisper 识别），说完即丢。

完整说明见 [PRIVACY.md](PRIVACY.md)；安全问题请读 [SECURITY.md](SECURITY.md)。

## 八、自己搭一套 / 参与开发

```bat
:: 1) 环境（Python 3.10+）
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple

:: 2) 跑测试（应全绿）
set QT_QPA_PLATFORM=offscreen
.venv\Scripts\python.exe -m pytest tests -q

:: 3) 打包成 exe（产物在 dist\）
.venv\Scripts\python.exe tools\build_exe.py
```

- 提交前跑一次 **`tools\release_check.py`**：它会扫出 API Key、`data/`、立绘、超大文件，发现问题返回 1。
